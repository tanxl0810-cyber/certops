# 初次公开版本整理

本目录是供公开发布的独立源码快照，不继承原内部项目的 Git 历史。

## 本次处理

- 公开材料仅包含应用源码、前端源码、通用测试、部署模板和重写的文档。
- 未包含原运维交接、内部环境脚本、真实云效 YAML、生产截图、数据库、恢复材料或访问凭据。
- 测试与前端中的业务域名、账号编号、流水线编号、Bucket 名称和主机地址改为示例值。
- 使用独立 PostgreSQL、非超级用户应用账号和从公开基础镜像构建的运行时。
- 飞书登录改为独立成员白名单；不访问其他系统的成员库。
- 新增 Apache-2.0 许可证、贡献和安全说明、第三方依赖说明及可选服务说明。

示例中的域名、文档 IP 和账号编号不代表维护者的真实部署。

## 上传方式

在 GitHub 创建自己的仓库后，**只上传本目录或发布 ZIP 中的文件**。不要将原内部仓库的 remote 改到公开仓库后直接 push，也不要复制原 `.git`，旧提交中可能仍有内部资料。

可在本目录创建新的 Git 历史，确认文件清单和扫描结果后再提交。不要使用 `git add -f` 绕过敏感文件忽略规则。
