# 常见问题

## CertOps 适合什么需求？

适合由可信运维团队管理阿里云 HTTPS 入口、自建或机房 Nginx 的场景，尤其是同一张证书绑定多个服务、需要核对换证范围和实际生效结果的情况。页面和示例见 [README](../README.md)，首次安装见 [TRY_IT](TRY_IT.md)。

## 可以免费自行部署和商业使用吗？

项目原创代码使用 [Apache-2.0](../LICENSE) 许可证，允许按许可证条款免费获取、自行部署和商业使用。部署、定制与维护协助是可选的付费服务，范围见 [SERVICES](../SERVICES.md)。云资源、域名和证书服务的第三方费用由使用者自行管理。

## 可以自动申请和续签 Let's Encrypt 证书吗？

当前没有通用 ACME / Let's Encrypt 自动申请适配器。已实现的申请与续签使用阿里云 SSL V1.0 已有资源包或 V2.0 订阅实例；也可以上传其他渠道提供的 PEM 证书和私钥。

## 会自动购买证书或替我续费云资源吗？

不会。用户自行管理证书资源包、订阅续费和可用申请额度，并显式开启证书的自动续签与相应目标的自动部署。具体权限与配置见 [ALIYUN](ALIYUN.md)。

## 支持哪些部署目标？

已适配的目标包括阿里云 DCDN、FC、GA、OSS、CLB、WAF，以及通过 SSH/SFTP 或云效流水线更新的 Nginx。具体证书槽位、共享监听器、网络和账号兼容性需要在相应环境中核对。系统示意图还包含扩展方向，详见 [SYSTEM_OVERVIEW](SYSTEM_OVERVIEW.md)。

## 证书上传后，所有关联服务都会自动更新吗？

保存证书版本、观测到服务正在使用证书、保存部署绑定，以及开启自动部署是不同的操作。新版本自动更新要求证书和目标同时开启自动部署，并通过校验；仅有云端使用关联的服务不会自动被加入更新范围。

## 云 API 返回成功，就算部署完成了吗？

任务还会核对目标实际提供的 TLS 证书。未生效时继续等待，失败时记录原因。提交结果不明时先核对实际指纹，并暂停该目标后续自动部署；处理步骤见 [OPERATIONS](OPERATIONS.md)。

## 能给不可信用户自助申请证书，或当成多租户 SaaS 使用吗？

当前所有登录成员都有管理员权限，没有租户隔离和细粒度 RBAC。飞书成员需要显式加入白名单。当前应由可信管理员团队使用，并保持单 worker 运行。

## 不提供云凭据也能先看界面吗？

可以。使用 Compose 启动独立数据库和控制台，先登录、改密，再用自己的测试证书体验导入与版本管理。仓库中的演示截图可以直接查看；没有独立的公开在线演示服务。步骤见 [TRY_IT](TRY_IT.md)。
