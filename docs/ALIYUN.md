# 阿里云接入

## 凭据和权限

使用专用 RAM 用户或角色，按实际使用的产品与资源授权。在控制台“访问凭据”中添加 AccessKey，必要时填写临时 STS Token；FC 2.0 使用场景还需填写自己的账号 UID。凭据在数据库加密保存，不写入项目源码。

[deploy/aliyun-certops-policy.json](../deploy/aliyun-certops-policy.json) 是覆盖多产品功能的权限参考模板，其中 `1234567890123456` 是虚构账号编号，必须替换为自己的账号 UID。按需删除不使用的产品 Action，并限制具体域名、Bucket、监听器或资源。

该模板不是针对所有账号的最小权限保证；部分查询 Action 使用 `Resource: "*"`。请结合阿里云当前 API 权限说明、RAM 策略检查及实际资源验证后使用。不要为了消除错误而直接授予整个账号的管理员权限。

模板未授予当前实现不使用的 DNS 删除、修改或停用权限。自动域名验证只新增精确匹配的验证记录；完成后如需清理旧记录，由运维人员按实际使用情况处理。

OSS 域名发现分别需要 `oss:ListBuckets` 和 `oss:ListCname`，部署需要相应 `oss:PutCname` 权限。发现流程读取资源及域名信息，不读取对象内容。

## 证书和目标

1. 先“测试连接”，再执行只读资源发现。
2. 在“证书管理 → 从阿里云导入”选择证书。列表阶段读取元数据；提交导入时才获取可用的证书内容及私钥。
3. 没有私钥的证书可以登记和监控，部署前必须补充匹配的私钥。
4. 在部署目标中核对绑定、域名、SNI、地域、监听器和证书槽位。发现到的资源不会自动绑定证书或开启自动部署。
5. 先完成一次受控测试部署、TLS 生效验证和回退，再启用自动化。

GA 默认与扩展证书、CLB 默认与扩展域名、WAF 不同接入方式的更新接口不同。共享监听器的新证书需要覆盖原证书的完整域名范围；不能只验证某一个域名就覆盖原有共享证书。

## 申请与续签

当前支持已有阿里云 SSL V2.0 订阅实例与 V1.0 资源包。填写自己实际拥有且可申请的实例或资源参数，核对联系人及 DNS 验证方式后启用自动续签。

资源包额度、免费测试证书限制、订阅状态及申请窗口由阿里云决定，软件不负责购买新实例、充值额度或自动付费续费。申请窗口请按当前产品规则设置，不对所有证书固定使用同一天数。

DNS 自动验证仅用于已配置的阿里云 DNS 账号；其他 DNS 服务可按任务中显示的验证记录手工处理。自动续签与自动部署分别启用。

原始接口说明可从[数字证书管理服务文档](https://help.aliyun.com/zh/ssl-certificate/)进入查询。不同产品版本和账号条件需要单独联调；接口适配及测试替身通过不等于该账号内所有产品已完成真实验收。
